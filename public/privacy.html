Kebijakan Privasi

Terakhir diperbarui: 21 November 2026

Aplikasi JumpIn ("kami") menghargai dan melindungi privasi setiap pengguna. Dokumen ini menjelaskan bagaimana kami mengelola data Anda saat menggunakan layanan JumpIn.

1. Data yang Kami Akses

JumpIn adalah pemutar musik berbasis web. Jika Anda memilih untuk masuk menggunakan akun Google / YouTube, kami hanya meminta izin akses baca (read-only) untuk menampilkan daftar putar (playlist) dan lagu yang Anda sukai langsung di aplikasi Anda.

2. Penyimpanan Data

Kami tidak menjual, menyewakan, atau membagikan data pribadi Anda kepada pihak ketiga. Token otorisasi disimpan secara lokal di browser perangkat Anda untuk kenyamanan penggunaan.

3. Layanan Pihak Ketiga

JumpIn memanfaatkan API publik YouTube dan stasiun radio resmi untuk streaming audio. Penggunaan layanan tersebut tunduk pada kebijakan privasi masing-masing penyedia layanan.

4. Kontak

Jika Anda memiliki pertanyaan tentang kebijakan privasi ini, Anda dapat menghubungi kami melalui repositori proyek atau email pengembang.
